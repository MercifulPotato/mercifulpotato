Item(by='cwyers', descendants=None, kids=None, score=None, time=1612240149, title=None, item_type='comment', url=None, parent=25996652, text='The value prop for Stadia is console-class gaming without hardware. Most devices where Stadia is able to run could run a port of a decade-old PC game. Similarly, most Steam games that could run unmodified on Stadia&#x27;s custom server hardware (running Linux, not Windows) would be games that don&#x27;t tax the hardware. Maybe that&#x27;s a better service than what Google rolled out? (GeForce Now seems to be doing better than Stadia, anecdotally.) But it&#x27;s not what Stadia is, and if they wanted some more recent console-class games, Valve as either a storefront or a game developer was not going to help them much. They would still have to deal with getting Ubisoft&#x2F;EA&#x2F;Activision&#x2F;whoever to do the ports.')
