Item(by='gspr', descendants=None, kids=[26000195], score=None, time=1612267879, title=None, item_type='comment', url=None, parent=25999559, text='If you&#x27;re using a wlroots compositor, then a workaround for sharing the whole screen is to use wf-recorder [1], which supports capturing the whole screen, and feeding its output to a virtual V4L2 device using v4l2loopback [2]. Software that is able to capture from a V4L2-compatible webcam (i.e. most) can them capture from the virtual device without knowing anything about Wayland. It&#x27;s not exactly the most CPU-efficient way of doing things, but if you can afford the cycles it works very well!<p>[1] <a href="https:&#x2F;&#x2F;github.com&#x2F;ammen99&#x2F;wf-recorder" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;ammen99&#x2F;wf-recorder</a><p>[2] <a href="https:&#x2F;&#x2F;github.com&#x2F;umlaeute&#x2F;v4l2loopback" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;umlaeute&#x2F;v4l2loopback</a>')
