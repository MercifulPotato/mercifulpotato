Item(by='cosmie', descendants=None, kids=None, score=None, time=1612390680, title=None, item_type='comment', url=None, parent=26018125, text='ARRAYFORMULA itself doesn&#x27;t exist in Excel, but they did recently add support for dynamic&#x2F;spilled arrays[1]. Which brings it close to (if not at) parity with ARRAYFORMULA.<p>It&#x27;s not even close to as handy as QUERY (in ease of use or intuitiveness), but they also recently introduced FILTER[2]. Which can be used in combination with other functions to replicate a subset of QUERY use cases.<p>My pet list of functions that have me reaching for Sheets are the regex ones[3][4][5]. Excel&#x27;s search and replace functions support basic wildcards[6], but anything more sophisticated than that quickly becomes infeasible, impractical, or impossible to replicate using Excel function built-ins and requires dropping writing into Javascript or VBA to write up a custom function.<p>That said, Excel has had a pretty nifty and powerful ETL tool hidden inside of it for the past ~7 years called Power Query[7]. This is essentially an entire app-within-an-app (and is a data processing engine in many Microsoft data products), complete with it&#x27;s own programming language[8] and compressed columnar data store format. For anyone with a development background, you can easily ramp up on Power Query&#x27;s language and do 90% of the work you need to do there, and obviate the need for complicated and fragile formulas to begin with.<p>[1] <a href="https:&#x2F;&#x2F;support.microsoft.com&#x2F;en-us&#x2F;office&#x2F;guidelines-and-examples-of-array-formulas-7d94a64e-3ff3-4686-9372-ecfd5caa57c7" rel="nofollow">https:&#x2F;&#x2F;support.microsoft.com&#x2F;en-us&#x2F;office&#x2F;guidelines-and-ex...</a><p>[2] <a href="https:&#x2F;&#x2F;support.microsoft.com&#x2F;en-us&#x2F;office&#x2F;filter-function-f4f7cb66-82eb-4767-8f7c-4877ad80c759" rel="nofollow">https:&#x2F;&#x2F;support.microsoft.com&#x2F;en-us&#x2F;office&#x2F;filter-function-f...</a><p>[3] <a href="https:&#x2F;&#x2F;support.google.com&#x2F;docs&#x2F;answer&#x2F;3098244" rel="nofollow">https:&#x2F;&#x2F;support.google.com&#x2F;docs&#x2F;answer&#x2F;3098244</a><p>[4] <a href="https:&#x2F;&#x2F;support.google.com&#x2F;docs&#x2F;answer&#x2F;3098292" rel="nofollow">https:&#x2F;&#x2F;support.google.com&#x2F;docs&#x2F;answer&#x2F;3098292</a><p>[5] <a href="https:&#x2F;&#x2F;support.google.com&#x2F;docs&#x2F;answer&#x2F;3098245" rel="nofollow">https:&#x2F;&#x2F;support.google.com&#x2F;docs&#x2F;answer&#x2F;3098245</a><p>[6] <a href="https:&#x2F;&#x2F;support.microsoft.com&#x2F;en-ie&#x2F;office&#x2F;using-wildcard-characters-in-searches-ef94362e-9999-4350-ad74-4d2371110adb" rel="nofollow">https:&#x2F;&#x2F;support.microsoft.com&#x2F;en-ie&#x2F;office&#x2F;using-wildcard-ch...</a><p>[7] <a href="https:&#x2F;&#x2F;support.microsoft.com&#x2F;en-us&#x2F;office&#x2F;getting-started-with-power-query-7104fbee-9e62-4cb9-a02e-5bfb1a6c536a" rel="nofollow">https:&#x2F;&#x2F;support.microsoft.com&#x2F;en-us&#x2F;office&#x2F;getting-started-w...</a><p>[8] <a href="https:&#x2F;&#x2F;docs.microsoft.com&#x2F;en-us&#x2F;powerquery-m&#x2F;" rel="nofollow">https:&#x2F;&#x2F;docs.microsoft.com&#x2F;en-us&#x2F;powerquery-m&#x2F;</a>')
