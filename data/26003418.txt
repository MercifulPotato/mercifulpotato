Item(by='aimor', descendants=None, kids=[26004365], score=None, time=1612285091, title=None, item_type='comment', url=None, parent=26000405, text='I remember learning how to get my site to display decently on different screen sizes. I got an abridged history of past attempts: &quot;handheld&quot; CSS media type, then media features &quot;device-height&#x2F;width, resolution, pointer, orientation, aspect ratio&quot;, some people try to use the User Agent, others target a huge list of specific device resolutions, webkit has a device pixel ratio?, it all seemed like a huge mess.<p>Then it turns out the solution isn&#x27;t CSS it&#x27;s the HTML &quot;meta&quot; tag:<p><pre><code>    &lt;meta name=&quot;viewport&quot; content=&quot;width=device-width, initial-scale=1.0&quot;&gt;\n</code></pre>\nOn top of that I use media queries to respond to the font size.<p><pre><code>    @media (max-width: 35rem)\n</code></pre>\nI&#x27;d love to know if there&#x27;s a better way, but this has been pretty good for me.')
