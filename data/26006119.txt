Item(by='stonesweep', descendants=None, kids=[26009579, 26006300], score=None, time=1612297412, title=None, item_type='comment', url=None, parent=26003795, text='trivia: `which` is not the <i>same</i> which on all distros - on Ubuntu for example it&#x27;s a super simple shell script named `which` which supports one single param (-a), not the compiled binary that you have on say Arch - and the features are different between them - I can&#x27;t for example run `which --skip-tilde which` on Ubuntu, invalid usage.<p>Many scripters who need wide compatibility of &quot;which&quot; fall back to the builtins `type` and `command` as they resolve any bash aliases set and give you a more truthful (sic) output than relying on `which` and bash is bash on all platforms:<p><pre><code>    # command -v which\n    &#x2F;usr&#x2F;bin&#x2F;which\n\n    # type which\n    which is hashed (&#x2F;usr&#x2F;bin&#x2F;which)\n</code></pre>\n$0.02 for your next adventure down the `which` rabbit hole. :)')
