Item(by='cytzol', descendants=None, kids=[26014997, 26014296], score=None, time=1612364314, title=None, item_type='comment', url=None, parent=26013556, text='&gt; And it&#x27;s not like it&#x27;s difficult to avoid hard coding<p>There are upsides to hard-coding the escape sequences that you aren&#x27;t mentioning. Using terminfo or ncurses requires an extra dependency with a clunky interface. Using tput requires spawning a process, which gets slow if you have to do it repeatedly. But simply hard-coding the escape sequences is dependency-free, as fast as printing, can be done in any language, and is going to work for at least 99.9% of the users out there.<p>I&#x27;m usually a big fan of &quot;use a standard interface rather than one particular implementation&quot;, but I haven&#x27;t found a solution, other than hard-coding the ANSI escape code set, that I&#x27;m happy with.')
