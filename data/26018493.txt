Item(by='threeseed', descendants=None, kids=[26018756, 26018553, 26018513], score=None, time=1612383038, title=None, item_type='comment', url=None, parent=26017784, text='I used to work for Australia&#x27;s national broadband network.<p>The issue with 5G is that there is a lot more software involved e.g. software defined networking, network function virtualization, edge computing, containerisation etc.<p>This makes securing the platform much more complex as you have to constantly validate that each piece of software is not able to access your core network or siphon user traffic.<p>Optical networks like you listed are pretty dumb so aren&#x27;t nearly as much of a threat.')
