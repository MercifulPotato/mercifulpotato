Item(by='johnvaluk', descendants=None, kids=[26008130], score=None, time=1612304207, title=None, item_type='comment', url=None, parent=26005251, text='I run NixOS on a variety of laptops as my daily driver. While there&#x27;s initially a steep learning curve, the time is well spent developing a reproducible configuration that you can quickly install on a new machine. I adapt the same configuration to generate a custom ISO that I write to a USB drive so I can boot into a familiar environment in a few minutes on almost any machine (running in RAM if there&#x27;s enough room). It doubles as an installer (as does any NixOS installation). This approach is also handy for booting ephemeral servers on any hardware (DNS, DHCP, etc.).<p>One of my hobbies is recycling older machines. I&#x27;ve installed NixOS on Chromebooks with 16GB internal drives. It&#x27;s possible if you remember to garbage collect after each successful upgrade (and stick to 64-bit machines).<p>I tend to treat my laptops as disposable and keep my important data on a file server so I don&#x27;t rely on local disk space.')
