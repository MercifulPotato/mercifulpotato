Item(by='mjw1007', descendants=None, kids=[26002575, 26002354], score=None, time=1612280467, title=None, item_type='comment', url=None, parent=26001179, text='I think Wayland has come too close to the following pattern, which I&#x27;ve seen in other cases of free software which have become controversial:<p>- decide it&#x27;s time to make a New Thing which will supersede the Old Thing rather than living beside it<p>- decide that some features of Old Thing will not be directly supported by New Thing; instead New Thing will be flexible enough that people could implement those features on top of it<p>- declare that the work done to support those features will have to be done by the people who want to use them<p>- declare that the time has come for New Thing to supersede Old Thing, before said work has been done<p>[Edit: this wasn&#x27;t intended to be a list of things that are individually bad ideas. It&#x27;s only the last, in combination with the others, that I think is ill-advised.]')
