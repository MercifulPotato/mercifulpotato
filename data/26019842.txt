Item(by='woodruffw', descendants=None, kids=None, score=None, time=1612390321, title=None, item_type='comment', url=None, parent=26019627, text='&gt; Would it make sense to enforce this by making the Homebrew python keg-only?<p>Maybe. I wasn&#x27;t privy to any discussions around making Python keg-only, but my experience with other formulae that are keg-only is that users will force-link keg-only packages into `&#x2F;usr&#x2F;local` anyways. What&#x27;s more, there are probably <i>enough</i> people out there who do just want a barebones Python 3 installation and don&#x27;t really care if it gets upgraded underneath them, and we&#x27;d like to provide that by default.<p>The Python ecosystem already contains mature tooling on both Linux and macOS for managing Python installations that are isolated from Homebrew and other system-level package managers, like pyenv. In general, I&#x27;d recommend using pyenv in parallel with Homebrew; that will get you the best of both worlds.')
