Ok, you don&#x27;t want to let other applications listen to keystrokes, record the screen, etc, by default?  Fine.  There should be some low level implementation that pops up a box <i>asking</i> the user if they wish to allow that app to do that, not outright breaking the practice!<p>Wayland feels like some ivy tower academic&#x27;s ideal of what a display system should be.  Everything usable is an &#x27;exercise left to the reader&#x27;.<p>Look, if you&#x27;re a dev working on an open source project meant to replace a critical piece of infrastructure, don&#x27;t be surprised when people don&#x27;t like or adopt it when it breaks a lot of their uses cases.')
