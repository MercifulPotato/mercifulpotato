Item(by='wenyuanyu', descendants=None, kids=None, score=None, time=1612272981, title=None, item_type='comment', url=None, parent=26000492, text='Good question! I am from the team built GraphScope.<p>Neo4j and JanusGraph are graph databases where GraphScope is not.<p>For end users, using GraphScope feels like using a python library like networkx (<a href="https:&#x2F;&#x2F;networkx.org&#x2F;" rel="nofollow">https:&#x2F;&#x2F;networkx.org&#x2F;</a>), and you can do graph analytics, gremlin queries and GNN sampling etc in a single place. But unlike NetworkX which does not support parallelization, the actual processing of (big) graphs is handled in a distributed k8s cluster in parallel on GraphScope.')
