Item(by='jeffbee', descendants=None, kids=None, score=None, time=1612389120, title=None, item_type='comment', url=None, parent=26019028, text='Protobuf provides the fixed64 type and when combined with `packed` (the default in proto3, optional in proto2) gives you a linear layout of fixed-size values. You would not get natural alignment from protobuf&#x27;s wire format if you read it from an arbitrary disk or net buffer; to get alignment you&#x27;d need to move or copy the vector. Protobuf&#x27;s C++ generated code provides RepeatedField that behaves in most respects like std::vector, but in as much as protobuf is partly a wire format and partly a library, users are free to ignore the library and use whatever code is most convenient to their application.<p>TL;DR variable-width numbers in protobuf are optional.')
