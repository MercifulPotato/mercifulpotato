Item(by='freefal', descendants=None, kids=[25997629, 25998168], score=None, time=1612238888, title=None, item_type='comment', url=None, parent=25996388, text='Back in &#x27;07, my school still used a custom email protocol called Blitzmail that verified the user by sending a random number, having the user encrypt the random number via DES using his password as the key and then send the result back. One problem (there were many) was that passwords were 8 characters and DES only wanted a 56-bit key so the protocol just dropped the <i>least</i> significant bit of each character. So while everyone thought they had one password, they really had 2^8 = 256 passwords, where &#x27;b&#x27; and &#x27;c&#x27; were interchangeable as were &#x27;d&#x27; and &#x27;e&#x27; and so on...<p>Now <i>that</i> was easy to crack.')
