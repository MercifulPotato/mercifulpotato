Item(by='number6', descendants=None, kids=None, score=None, time=1612375174, title=None, item_type='comment', url=None, parent=26016571, text='I have it from different DPAs that encrypted data are not PPI under the GDRP. The case might be different for passwords but you have to think around the corner a bit: You compare two hashes when you compare a password - you don&#x27;t compare the password itself (the actual string in the form) - so what Identifies you as the person to the computer is not your password but the hash. So the hash itself is PII.\nWhy isn&#x27;t this true for encryption? Well good encryption in principle should not look different from random data. Will the same file encrypted with the same key produce the same outcome? Well - no. At least it shouldn&#x27;t. So its not possible to identify someone with it like with a hash value.\nI can only speculate about the rational but this is the only explanation that come to my mind.')
