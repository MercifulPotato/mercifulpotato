Item(by='felixr', descendants=None, kids=None, score=None, time=1612368890, title=None, item_type='comment', url=None, parent=26012040, text='I have a simple custom solution that works well for me. Snippets are just files in a directory. The filename is the snippet name. If the file is executable, it uses whatever is returned from running it. You can use zenity [0] to create forms or run rofi&#x2F;dmenu to select &quot;arguments&quot; in those scripts.<p>It uses `rofi` and `xdotool`:<p><pre><code>  #!&#x2F;bin&#x2F;bash\n  SNIPPET_DIR=&quot;${HOME}&#x2F;.config&#x2F;snipex&quot;\n  DMENU=&quot;rofi -dmenu -b -p Snippet:&quot;\n  XSEL=&quot;&#x2F;usr&#x2F;bin&#x2F;xsel --clipboard --input&quot;\n  SNIPPET=$(ls -1 &quot;${SNIPPET_DIR}&quot; | ${DMENU})\n  FILE=&quot;${SNIPPET_DIR}&#x2F;${SNIPPET}&quot;\n  \n  STRIP_NEWLINE=&quot;head -c -1&quot;\n  \n  if [ -x &quot;${FILE}&quot; ]; then\n    # snippet is executable -&gt; run it and copy the result\n    ${FILE} | ${STRIP_NEWLINE} | ${XSEL}\n  elif [ -f &quot;${FILE}&quot; ]; then\n    # copy the contents of the file\n    ${STRIP_NEWLINE} ${FILE} | ${XSEL}\n  else\n    # clean clipboard\n    echo &quot;&quot; | ${XSEL}\n  fi\n  \n  xdotool key --clearmodifiers &quot;Shift+Insert&quot;\n</code></pre>\nedit: and I have an xbindkeys config to run this script when I press Meta+,<p>[0]: <a href="https:&#x2F;&#x2F;help.gnome.org&#x2F;users&#x2F;zenity&#x2F;stable&#x2F;forms.html.en" rel="nofollow">https:&#x2F;&#x2F;help.gnome.org&#x2F;users&#x2F;zenity&#x2F;stable&#x2F;forms.html.en</a>')
