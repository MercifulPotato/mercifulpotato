Item(by='juntan', descendants=None, kids=None, score=None, time=1612388234, title=None, item_type='comment', url=None, parent=26018541, text='In Perspective (<a href="https:&#x2F;&#x2F;github.com&#x2F;finos&#x2F;perspective" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;finos&#x2F;perspective</a>), we use Apache Arrow as a fast, cross-language&#x2F;cross-network data encoding that is extremely useful for in-browser data visualization and analytics.\nSome benefits:<p>- super fast read&#x2F;write compared to CSV &amp; JSON (Perspective and Arrow share an extremely similar column encoding scheme, so we can memcpy Arrow columns into Perspective wholesale instead of reading a dataset iteratively).<p>- the ability to send Arrow binaries as an ArrayBuffer between a Python server and a WASM client, which guarantees compatibility and removes the overhead of JSON serialization&#x2F;deserialization.<p>- because Arrow columns are strictly typed, there&#x27;s no need to infer data types - this helps with speed and correctness.<p>- Compared to JSON&#x2F;CSV, Arrow binaries have a super compact encoding that reduces network transport time.<p>For us, building on top of Apache Arrow (and using it wherever we can) reduces the friction of passing around data between clients, servers, and runtimes in different languages, and allows larger datasets to be efficiently visualized and analyzed in the browser context.')
