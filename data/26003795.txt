Item(by='freedomben', descendants=None, kids=[26006119, 26003976, 26006507, 26005228, 26003824], score=None, time=1612286836, title=None, item_type='comment', url=None, parent=26003525, text='FHS and distros that follow it aren&#x27;t perfect, but it <i>does</i> make a big difference.  I prefer Fedora-based and Arch-based flavors for that reason.  It&#x27;s usually pretty easy to find stuff.<p>Backtrack used to do something like this and while it was easier compared to a lot of other debian&#x2F;ubuntu based things, I still ran into some pain points.<p>A great command to keep handy is<p><pre><code>    ls -la `which &lt;program&gt;`\n</code></pre>\nThat will usually find you the binary right away, and if it&#x27;s a symlink or something you&#x27;ll see it in the ls output.  It&#x27;s especially useful to me because (generally speaking) I put stuff I build myself in ~&#x2F;bin rather than `&#x2F;usr&#x2F;local&#x2F;bin` so I can quickly tell if I&#x27;m using my own build or the package manager&#x27;s.<p>Edit:  FHS == Filesystem Hierarchy Standard - <a href="https:&#x2F;&#x2F;en.wikipedia.org&#x2F;wiki&#x2F;Filesystem_Hierarchy_Standard" rel="nofollow">https:&#x2F;&#x2F;en.wikipedia.org&#x2F;wiki&#x2F;Filesystem_Hierarchy_Standard</a>')
