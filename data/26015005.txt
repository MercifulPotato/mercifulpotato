Item(by='KingMachiavelli', descendants=None, kids=[26017415, 26015169], score=None, time=1612368676, title=None, item_type='comment', url=None, parent=26014454, text='I typically keep a Windows VM running for the main purpose of using my brokers very powerful trading desktop application. While it is very useful and can do all sorts of calculations &amp; graphing, it is kind of slow and the UI is a little cumbersome. The number of clicks to add a stock to a watchlist is very high, etc. In comparison, it takes 1 button to add a stock to mop [1] and I can keep it in a &#x27;dropdown&#x27; terminal window controlled by a keyboard shortcut.<p>Unless you are a HF trader, you probably only need the stock price within a few minutes unless you are about to place a trade. (And typically all these terminal stock tickers are doing is scraping these sites anyway so the data is about the same.) Therefore, during the day I can watch stocks in the comfort of my terminal using mop [1] (or this if this has more features and is as easy to use), and if anything strikes my eye I can then go to my stock trading terminal and watch things more precisely.<p>I also do have a custom search engine that can open any stock ticker to finviz.com but I&#x27;d rather not have to have yet another account on some random website that either has distracting ads and&#x2F;or pushes me to pay for more features.<p>There is a very large UX vs features trade off when it comes to anything stock related so it makes sense to use multiple tools.')
