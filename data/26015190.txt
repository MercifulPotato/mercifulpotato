So you basically have to know the password to get to the right directory.</i><p>You could attack the site by cracking the password to get the hash, or you could work out a way to make the web server list all the available directories instead. It only takes a simple mistake on the part of Github to enable directory listings and everyone will have access.<p>FWIW I trust that Github won&#x27;t do that and I think you&#x27;ll be fine, but as a method of securing something on the web using an obscure directory name is a terrible idea.')
