Item(by='roblabla', descendants=None, kids=[25999472], score=None, time=1612262383, title=None, item_type='comment', url=None, parent=25999280, text='The system call interface is usually written in an unsafe language such as asm anyways. Going through the libc is very unlikely to actually introduce vulnerabilities, especially if going through the lowest level function that directly wrap the syscall.<p>Not using the libc was always a risky proposition on BSDs anyways. They don&#x27;t have a stable kernel ABI the same way the Linux kernel does. From OpenBSD&#x27;s perspective, the stable ABI is the libc, and anything using the kernel ABI directly is liable for breakage with each update.')
