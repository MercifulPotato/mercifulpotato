Item(by='jart', descendants=None, kids=[26001490], score=None, time=1612273811, title=None, item_type='comment', url=None, parent=25998732, text='No they don&#x27;t. Only Windows forbids developers from linking static binaries. That&#x27;s because they change the SYSCALL ordinals every few months. Which means that in order to load a program on Windows you have to give up control of the virtual memory address space to the operating system so that it can load DLLs at arbitrary addresses.<p>Unix systems have never had that restriction. Because if you use the official libc and pass -static to gcc then that means the &quot;stable api&quot; creates a binary that depends on the kernel abi. If the kernel authors break the abi then it means you need to recompile all your software in order to upgrade.')
