Item(by='ATsch', descendants=None, kids=[26000219], score=None, time=1612268859, title=None, item_type='comment', url=None, parent=25999968, text='&gt; The only copy&#x2F;paste behavioral difference I&#x27;ve noticed on Wayland is that I lose the copied data if I close the source program.<p>This is because sway by default does not provide a &quot;clipboard manager&quot; component. It has been the case for a long time that the clipboard is only actually populated when you paste, copying merely stores a reference. This is so you can copy&#x2F;paste multi gigabyte files without running out of memory. A clipboard manager component solves this issue by intelligently saving your clipboard as applications come and go.')
