Item(by='sguav', descendants=None, kids=[26000984], score=None, time=1612259680, title=None, item_type='comment', url=None, parent=25998794, text='Doing VHDL designs for a living here, using SystemVerilog once in a while when absolutely required. Take my words with a good pinch of salt!<p>SV is anyway a hardware description language, so you still think and code in terms of modules and signals (wires) to be connected. But if you want to create structures that use variables and have a more &quot;procedural&quot; style, I find that SV is more agile than VHDL for this specific purpose.<p>If you want real high level languages for hardware there are tools that provide synthesis from C&#x2F;C++, Python and more software oriented languages.')
