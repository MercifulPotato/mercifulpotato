Item(by='horsawlarway', descendants=None, kids=None, score=None, time=1612307148, title=None, item_type='comment', url=None, parent=26006345, text='Disagree with you on 3.  &#x27;unknown&#x27; is handy to prevent &#x27;any&#x27;s from leaking into the codebase.  It&#x27;s very easy to accidentally assign an &#x27;any&#x27; to another variable and then return it, or to accidentally read a property off of it before ensuring it exists.<p>Unknown is basically asking the dev to confirm the choice (ideally through a typeguard, but also with a simple cast).<p>And if you&#x27;re using a typeguard, just define the argument as &#x27;any&#x27; ex -<p><pre><code>  type AType = {\n    c: string\n  }\n\n  let a: unknown = {\n    c: &#x27;test&#x27;,\n  }\n\n  if (isAType(a)) {\n    console.log(a.c) &#x2F;&#x2F; no type errors!\n  }\n\n  function isAType(a: any): a is AType {\n    return typeof a.c == &#x27;string&#x27;\n  }</code></pre>')
