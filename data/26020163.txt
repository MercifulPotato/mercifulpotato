Item(by='Communitivity', descendants=None, kids=[26020241, 26024378, 26021432], score=None, time=1612392024, title=None, item_type='comment', url=None, parent=26019516, text='The article points out that while far from being widely accepted, this theory is getting a new look because of some experimental evidence that supports it.<p>&gt; I don&#x27;t think there&#x27;s any real doubt that memory is<p>&gt; stored in neurons, this is really a fringe theory.<p>All theories are fringe theories at first, that&#x27;s where they start (as hypothesis before there&#x27;s any experimental evidence or mathematical proofs).<p>I would agree that there is little doubt that memory is stored in neurons. However, that does not exclude some memory being stored elsewhere. It&#x27;s generally accepted that the brain stores memories first in short term memory, and then after a time some of those memories are stored in long term memory, with the memories chosen according to some criteria.<p>I could see RNA memory as a third stage of memory storage. Memories that the brain views as high impact to the species according to some criteria might get copied from long term memory into RNA memory to be passed on to future generations, accessible only by subconscious.')
