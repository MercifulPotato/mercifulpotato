Item(by='LukeShu', descendants=None, kids=None, score=None, time=1612326184, title=None, item_type='comment', url=None, parent=26004598, text='The (1) and (5) and so on are the section of &quot;the manual&quot; that is being referred to; &quot;the manual&quot; referring to the entire system manual, and the one command you&#x27;re looking up being just one page in that manual (hence &quot;man page&quot;).<p>As for what those sections are, `man man` tells me (my system gets this man page from the &quot;man-db&quot; project <a href="https:&#x2F;&#x2F;www.nongnu.org&#x2F;man-db&#x2F;" rel="nofollow">https:&#x2F;&#x2F;www.nongnu.org&#x2F;man-db&#x2F;</a> ; your system may use a man page of different authorship, but it should tell you roughly the same thing):<p><pre><code>    The table below shows the section numbers of the manual followed\n    by the types of pages they contain.\n\n    1   Executable programs or shell commands\n    2   System calls (functions provided by the kernel)\n    3   Library calls (functions within program libraries)\n    4   Special files (usually found in &#x2F;dev)\n    5   File formats and conventions, e.g. &#x2F;etc&#x2F;passwd\n    6   Games\n    7   Miscellaneous (including macro packages and conventions), e.g. man(7), groff(7)\n    8   System administration commands (usually only for root)\n    9   Kernel routines [Non standard]\n</code></pre>\nSometimes the number has a suffix; for example, the &quot;p&quot; suffix as in (1p) or (3p) indicates that the man page is taken from POSIX (and therefore might be missing features that your version has; but also that everything in it can probably be relied on on other systems).  Or (3perl) which indicates that it&#x27;s a Perl library function instead of a C library function.<p>You can tell `man` which section you&#x27;re looking in like `man 5 passwd`.  This is useful for looking up passwd(5) which describes the &#x2F;etc&#x2F;passwd file, rather than passwd(1) which describes the `passwd` command to change your password.  Or `man 2 signal` to describe the &quot;signal&quot; system-call instead of the signal(3p) libc function, or `man 7 signal` to get an overview and listing of signals.')
