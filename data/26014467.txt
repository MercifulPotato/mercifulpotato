Item(by='mempko', descendants=None, kids=None, score=None, time=1612366177, title=None, item_type='comment', url=None, parent=26013909, text='There are details about blockchains that are often missed. That is, not only is trust distributed, but software execution is distributed. Smart contracts in bitcoin and eth are an interesting concept. Think AWS lambda but distributed.<p>So user centric programming abstractions where users can execute queries and directly put data in the database is interesting concept. Of course you can also do this without a blockchain too if you can deal with a trusted party.')
