Item(by='DaiPlusPlus', descendants=None, kids=None, score=None, time=1612316926, title=None, item_type='comment', url=None, parent=26009362, text='Even without its basis in the history of COM, the I-prefix for interfaces types in .NET makes sense because interfaces-types are very structurally and semantically different to &quot;a type&#x27;s interface&quot; - so having some way to quickly distinguish them at-a-glance is necessary.<p>I started off in .NET and when I was using Java it wasn&#x27;t immediately obvious what types were interfaces or not (e.g. &quot;List&quot; is an interface in Java, and also especially when the interface suggests what the implementation is).<p>C# can be described as a considerably better Java - but I wish they didn&#x27;t inherit Java&#x27;s interfaces vs. classes model and instead had something that enables some form of structural-typing: something like TypeScript&#x27;s interfaces or Swift&#x27;s protocols.')
