Item(by='ploxiln', descendants=None, kids=[26006935, 26007927, 26006171, 26009881, 26008758], score=None, time=1612295638, title=None, item_type='comment', url=None, parent=26003525, text='GoboLinux install layout is a cool concept.<p>However, it&#x27;s not hard to figure out where files were installed, and what files are from. The package manager keeps track of all of that, and you can ask it. Example for debian or ubuntu:<p><pre><code>  # list all files from package\n  dpkq-query -L &lt;package&gt;\n  dpkg-query -L &lt;package&gt; | grep bin&#x2F;  # see just commands\n\n  # find what package a file is from\n  dpkg-query -S &#x2F;path&#x2F;to&#x2F;some&#x2F;thing\n</code></pre>\nI use equivalent commands in Archlinux (pacman ...) and they certainly exist for redhat&#x2F;fedora but I&#x27;m not familiar with those.<p>For stuff not installed as packages, hopefully it&#x27;s either in a single directory in &#x2F;opt, or among a small collection of stuff spread in &#x2F;usr&#x2F;local, or in a self-contained directory in your home folder.')
