Item(by='acdha', descendants=None, kids=[26021114], score=None, time=1612397611, title=None, item_type='comment', url=None, parent=26020697, text='The key part which you missed is that everything is automated, always installed in an isolated virtual environment, the package are automatically tracked and updated, and the tools which make this happen are installed from Homebrew and update at the same time.<p>As to why there are two tools, it&#x27;s because they have separate goals: pipx provides a robust way to manage global installs of Python utilities in per-tool virtualenvs while tools like poetry or pipenv are aimed at projects you&#x27;re developing and handle things like automating the process of installing updates &amp; updating the corresponding metadata files so you can ship clean updates. All of them use virtualenvs and pip underneath — it&#x27;s just a modern workflow.<p>The key part is recognizing that the problem comes from trying to fight updates: software changes and accepting that means moving to a workflow which automates that rather than spending time trying to freeze everything in amber. Learning to use a tool every decade or so is a LOT less time consuming than doing this by hand. The average poster in this thread has already spent more time on this topic than my projects have needed for the mechanics of installing Python packages in any given year.')
