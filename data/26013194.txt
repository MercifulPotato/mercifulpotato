Item(by='rwmj', descendants=None, kids=[26015884, 26013251], score=None, time=1612356992, title=None, item_type='comment', url=None, parent=26012874, text='This is really a thing which happens with the glibc allocator and long-lived applications.  Back in the day I had a custom chat server which consistently used more and more memory until after about a month it ran out of memory and crashed.  I spent quite a while investigating, even annotating every malloc&#x2F;free in the program to find the leak, only to conclude that there was simply no leak at all in the program and it was some effect in the allocator itself.  (Rather than spending time trying other allocators, the &quot;solution&quot; was to schedule a server restart every couple of weeks, early in the morning when no one was using the system.)')
