Item(by='Fellshard', descendants=None, kids=[26002872, 26002986], score=None, time=1612282434, title=None, item_type='comment', url=None, parent=26002485, text='If every implementation of a protocol seems stuck with deal-breaking bugs or incompatibilities, it&#x27;s time to start asking whether the protocol itself has some problems that make it impossible to implement consistently - unstated assumptions, for example, in the reference implementation that never made it to the protocol spec.<p>For a modern example of this in action, see Bluetooth and the madhouse of device &#x27;quirks&#x27; you have to settle with day-to-day, since each device has subtly protocol-breaking opinions on how to implement it.')
