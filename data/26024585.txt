Item(by='Twisol', descendants=None, kids=[26024626], score=None, time=1612439576, title=None, item_type='comment', url=None, parent=26024566, text='As with the TypeScript examples, we can make the top-level apply method generic instead of the whole class to avoid some casts. In particular, notice that the &lt;T&gt; inferred from calling Circle() and Rectangle() is the unmeaningful &lt;Object&gt;.<p>The downside is that Java doesn&#x27;t let you implement generic methods with lambdas, which is <i>silly</i>, so you have to use an anonymous subclass. But at least the call-side uses stay the same.<p>(And then, combining the `_Circle` and `_Rectangle` interfaces gets you to a more canonical visitor pattern, at the expense of lambdas at the call-site.)<p><pre><code>    public interface Shape {\n      interface _Circle&lt;T&gt; {\n        T apply(int x, int y, int r);\n      }\n      interface _Rectangle&lt;T&gt; {\n        T apply(int x, int y, int w, int h);\n      }\n\n      &lt;T&gt; T apply(_Circle&lt;T&gt; circle, _Rectangle&lt;T&gt; rectangle);\n\n      static Shape Circle(int x, int y, int r) {\n        return new Shape() {\n          public &lt;T&gt; T apply(_Circle&lt;T&gt; circle, _Rectangle&lt;T&gt; rectangle) {\n            return circle.apply(x, y, r);\n          }\n        };\n      }\n      static Shape Rectangle(int x, int y, int w, int h) {\n        return new Shape() {\n          public &lt;T&gt; T apply(_Circle&lt;T&gt; circle, _Rectangle&lt;T&gt; rectangle) {\n            return rectangle.apply(x, y, w, h);\n          }\n        };\n      }\n\n      static double area(Shape shape) {\n        return shape.apply(\n            (x, y, r) -&gt; Math.PI * r * r,\n            (x, y, w, h) -&gt; 1. * w * h\n        );\n      }\n\n      static void main(String[] args) {\n        var exampleCircle = Circle(2, 1, 4);\n        var exampleRectangle = Rectangle(1, 3, 10, 7);\n\n        System.out.println(area(exampleCircle));\n        System.out.println(area(exampleRectangle));\n      }\n    }</code></pre>')
