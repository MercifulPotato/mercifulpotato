One type system was added to Racket called Typed Racket. No new features were needed in the language or tooling, they just used Racket macros to build a Racket with static compiler errors which integrates with the IDE.<p>Two similar cases. One is Typescript. That&#x27;s a new language with different syntax, a new compiler which targets JS. It also provides its own tooling for IDEs. Another is Python. Over time there were PEPs to add syntax for type hints, and now type systems are being added to the language.<p>When Racket did this, they were able to do it in Racket without adding more features to the compiler or IDE. There&#x27;s built in support for static analysis, compiler errors, editor integration. Not to mention a way to organize all the information you need to do type checking in the compile steps, and make that information accessible in the right places. The new type safe Racket was built using plain ol Racket.<p>There&#x27;s a reasonably accessible paper about this here: <a href="https:&#x2F;&#x2F;www2.ccs.neu.edu&#x2F;racket&#x2F;pubs&#x2F;scheme2007-ctf.pdf" rel="nofollow">https:&#x2F;&#x2F;www2.ccs.neu.edu&#x2F;racket&#x2F;pubs&#x2F;scheme2007-ctf.pdf</a><p>So here are some of my ideas:<p>1. Play around with static analysis checks. I want to rebuild Typescript style structural inference to Racket. I like how TS is unsound (has no runtime performance penalty for mixing untyped code), and is easily disabled via any if it&#x27;s in the way. I love the focus on great error messages. Maybe one day I will contribute to Typed Racket :)<p>Making your own compiler error appear in Racket is just 5 lines of code. <a href="https:&#x2F;&#x2F;gist.github.com&#x2F;srcreigh&#x2F;a0a087adc26e15af0160e8866d48cd1c" rel="nofollow">https:&#x2F;&#x2F;gist.github.com&#x2F;srcreigh&#x2F;a0a087adc26e15af0160e8866d4...</a><p>2. New syntax for creating structs. Racket had structs that are initialized like (point 1 2). What if you want keyword syntax ie (point #:x 1 #:y 2)? What if you want that to work with match too? Do you want a JS-style syntax such as (point #:x #:y 2) which pulls in x as an identifier? You can do all this! The rebellion library is pretty awesome in this regard [1], with some sample usage of it in a script here [2].<p>[1]: <a href="https:&#x2F;&#x2F;docs.racket-lang.org&#x2F;rebellion&#x2F;Data_Types.html" rel="nofollow">https:&#x2F;&#x2F;docs.racket-lang.org&#x2F;rebellion&#x2F;Data_Types.html</a>\n[2]: <a href="https:&#x2F;&#x2F;github.com&#x2F;srcreigh&#x2F;shift-remapper&#x2F;blob&#x2F;main&#x2F;generate.rkt" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;srcreigh&#x2F;shift-remapper&#x2F;blob&#x2F;main&#x2F;generat...</a>')
