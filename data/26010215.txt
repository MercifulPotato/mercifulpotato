Item(by='Blikkentrekker', descendants=None, kids=[26010387], score=None, time=1612322421, title=None, item_type='comment', url=None, parent=26009486, text='&gt; <i>&#x2F;etc&#x2F; is per-system configuration overrides. There is a goal to move to &quot;empty &#x2F;etc&#x2F;&quot;, meaning you should be able to remove all files in &#x2F;etc&#x2F; and still have a functioning system.</i><p>I find this goal to be rather frustrating.<p>It means that software will hardcode it&#x27;s default configuration when it cannot find a file in `&#x2F;etc`, and it makes it very hard to deduce what exactly can be configured.<p>I strongly dislike software that will simply apply a default state when it cannot encounter a certain configuration in it&#x27;s configuration file for this reason.<p>I favor that software simply refuse to start with a clear warning as to why, when it cannot find a configuration option in it&#x27;s configuration file.<p>Applying a default on a missing key is another case of weak typing; I would hope that lessons were learned by now that guessing what the user wants in case of error is a bad idea.<p>What is even worse is software that simply ignores malformed keys, and applies a default value anyway, giving rise to not only innocent mistakes by typoes, but some malicious exploits that were found by putting zero-width spaces into keys to trick administrators <i>viā</i> social engineering.')
