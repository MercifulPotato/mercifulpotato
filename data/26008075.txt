Item(by='Blikkentrekker', descendants=None, kids=[26008418], score=None, time=1612305977, title=None, item_type='comment', url=None, parent=26003525, text='In almost any system, finding out where what files belong to a package is a trivial operation for the package manager to list.<p>The idea that a package is “installed somewhere” rather than “installed” and has files that “belong to it” seems to be a <i>Windows</i>-ism in mentality, where it is common to start applications by navigating to the folder they are installed in, and starting an execution there from an absolute path.<p>Many packages&#x27; files consist of nothing more than adding more fonts to the system, it seems a bad idea to me, to have all that in a per-package folder, rather than simply in `&#x2F;usr&#x2F;share&#x2F;fonts`, and have the package manager track what file therein belongs to what package.')
