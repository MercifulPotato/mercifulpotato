Item(by='pmoriarty', descendants=None, kids=[26003378], score=None, time=1612284215, title=None, item_type='comment', url=None, parent=26002364, text='<i>&quot;But Xorg doesn&#x27;t have to run as root&quot;</i><p>All the hand wringing over root privilege escalation on Linux is almost irrelevant for most single-user systems, as since there&#x27;s really only one non-root account which usually has all the data the user cares about, getting access to just that non-root account would be disaster enough for the user.[1]<p>So if Wayland&#x27;s design is standing in the way of doing useful things because they&#x27;re concerned about root privilege escalation, they&#x27;ve got their priorities mixed up.<p>[1] - not to mention that once a non-root account is exploited then getting root in some other way, even if Wayland itself can&#x27;t be exploited, is usually not difficult.')
