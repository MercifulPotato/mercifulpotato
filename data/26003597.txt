You raise a great point that is worth clarifying though. All logs, metrics and future traces are stored in S3&#x2F;GCS (and yes <i>metrics</i> are stored in TSDB format). While this does not allow a single query language to ask questions across all these sources in one query (yet), it is absolutely possible to build what Datadog is with a new user interface. To go even further, now that it’s all in one place (S3&#x2F;GCS) other technologies can be leveraged to create a higher level query language across everything, such as PrestoDB (one would have to build backends for it), or even a new dedicated open source columnar store.')
