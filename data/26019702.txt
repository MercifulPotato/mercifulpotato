Item(by='zten', descendants=None, kids=None, score=None, time=1612389471, title=None, item_type='comment', url=None, parent=26019442, text='The important part to focus on is _between processes_.<p>Consider Spark and PySpark. The Python bits of Spark are in a sidecar process to the JVM running Spark. If you ask PySpark to create a DataFrame from Parquet data, it&#x27;ll instruct the Java process to load the data. Its in-memory form will be Arrow. Now, if you want to manipulate that data in PySpark using Python-only libraries, prior to the adoption of Arrow it used to serialize and deserialize the data between processes on the same host. With Arrow, this process is simplified -- however, I&#x27;m not sure if it&#x27;s simplified by exchanging bytes that don&#x27;t require serialization&#x2F;deserialization between the processes or by literally sharing memory between the processes. The docs do mention zero-copied shared memory.')
