Item(by='seniorsassycat', descendants=None, kids=None, score=None, time=1612339802, title=None, item_type='comment', url=None, parent=26010829, text='I think the suggestion is for typescript to have one none type equal to undefined | null. The type checker could not error on undefined when null is required or vice versa.<p>Then code should use != null comparisons which match the none types semantics without needing runtime code generation.<p>I think this would violate another typescript principles that existing libraries and patterns should be expressable in typescript.<p>Some schmuck wrote a library that accepts null but not undefined so typescript has to distinguish them.')
