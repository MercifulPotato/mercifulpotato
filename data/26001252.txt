Item(by='node01', descendants=None, kids=None, score=None, time=1612275933, title=None, item_type='comment', url=None, parent=26001058, text='Creator here!<p>What: SnippetDrop [1] is a VS Code extension for encrypted code snippet sharing without leaving VS Code. You can download it on the VS Code Marketplace [2].<p>Why: I built it to replace the process of sending snippets over Slack, generating private gists, or needing to share secrets&#x2F;env vars via password managers or encrypted emails.<p>Encryption: Snippets are encrypted&#x2F;decrypted locally in the extension using node-rsa [3] and asymmetric 2048-bit RSA. Private keys never leave your device. Encrypted snippets are temporarily hosted on servers until the recipient&#x27;s device is available to download them.<p>How It Works: Install extension, login with GitHub, right click any text selection or file, click Send via SnippetDrop, and enter the recipient&#x27;s GitHub username.<p>Learn More: The extension source is on GitHub [4]. You can also watch the extension in action on the website [1].
