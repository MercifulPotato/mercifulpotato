Item(by='chrismorgan', descendants=None, kids=None, score=None, time=1612317245, title=None, item_type='comment', url=None, parent=26008425, text='Another common convention is to select a suitable letter: for types with no particular meaning, go T, U, V, <i>&amp;c.</i>; for types with meaning, see if there’s a better letter, e.g. Map&lt;K, V&gt; for a key-value map.<p>Rust convention is to mostly use this style of single-letter generics, but not to shy away from using longer names like regular type where useful (but not to prefix them like TFoo).')
