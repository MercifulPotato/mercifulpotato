There was no ability to write other X11 display servers from the spec alone. You either did what Xorg did bug for bug or apps broke. By having many different implementations all speaking a common protocol you make it harder to calcify the behaviors of any one implementation and ensure that the spec is what apps code against.<p>People seem to like that we have many browser implementations but when it comes to display servers it seems like they want Chrome to rule them all.')
