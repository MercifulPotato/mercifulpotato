Item(by='carapace', descendants=None, kids=None, score=None, time=1612371513, title=None, item_type='comment', url=None, parent=26014693, text='FWIW, here&#x27;s an example of a simple programming task in Joy, the derivation of the <i>step</i> combinator.  It might not make a lot of sense without familiarity with Joy, however, the thing to notice is the smooth algebraic form of programming.  Making simple obvious decisions at each point leads to a concise and correct program.  That&#x27;s &quot;the function-level programming style of John Backus&#x27;s FP.&quot; in action.  You can do it in Haskell (et. al.) too but I find it much easier in Joy. YMMV.<p>The <i>step</i> combinator accepts a list and a quoted program and runs the program on each item in the list in turn.  (Use it to write e.g. sum of list of ints, etc.)<p><pre><code>     [] [P] step\n  -----------------  Empty list, no-op.\n\n\n     [X|Xs] [P] step\n  -----------------------  Non-empty list, run P and recur.\n     X P [Xs] [P] step\n\n In terms of branch and x:\n\n   step == [F] x\n\n So:\n\n   [L] [P] step\n   ------------------\n   [L] [P] [F] x\n   ------------------\n   [L] [P] [F] F\n\n First, get the flag value and roll&lt; it to the top for a branch:\n\n   F  == F′ F″\n   F′ == [?] dipd roll&lt;\n\n   [L] [P] [F] F\n   ---------------------------\n   [L] [P] [F′ F″] F′ F″\n   ---------------------------------------\n   [L] [P] [F′ F″] [?] dipd roll&lt; F″\n\n How that works out:\n\n   [L]   [P] [F] [?] dipd roll&lt; F″\n   [L] ? [P] [F]          roll&lt; F″\n   [L] b [P] [F]          roll&lt; F″\n   [L]   [P] [F] b              F″\n\n Now we can write a branch:\n\n   F″ == [Ff] [Ft] branch\n\n   [L] [P] [F] b F″\n   ------------------------------------\n   [L] [P] [F] b [Ff] [Ft] branch\n\n The false case is easy:\n\n   Ff == pop popop\n\n   ... [] [P] [F] Ff\n   ... [] [P] [F] pop popop\n   ... [] [P]         popop\n   ... \n\n\n The true case is a little more fun:\n\n   ... [X|Xs] [P] [F] Ft\n\n We need to uncons that first term, run a copy of P, and recur (recurse?\n I think re-curse means to &quot;curse again&quot; so it must be &quot;recur&quot;.)\n\n   Ft == Ft′ Ft″\n   Ft′ == [uncons] dipd\n\n   ... [X|Xs]        [P] [F] [uncons] dipd Ft″\n   ... [X|Xs] uncons [P] [F]               Ft″\n   ... X [Xs]        [P] [F]               Ft″\n\n So now we run a copy of P:\n\n   ... X [Xs] [P] [F] Ft″\n\n   Ft″ == [dup dipd] dip Ft‴\n\n   ... X   [Xs] [P]          [F] Ft″\n   ... X   [Xs] [P]          [F] [dup dipd] dip Ft‴\n   ... X   [Xs] [P] dup dipd [F] Ft‴\n   ... X   [Xs] [P] [P] dipd [F] Ft‴\n   ... X P [Xs] [P]          [F] Ft‴\n\n And now all that remains is to recur on F:\n\n   Ft‴ == x\n\n   ... X P [Xs] [P] [F] x\n\n\n Collecting the definitions, we have:\n\n   step == [F] x\n     F  == F′ [Ff] [Ft] branch\n     F′ == [?] dipd roll&lt;\n     Ff == pop popop\n     Ft == Ft′ Ft″ x\n    Ft′ == [uncons] dipd\n    Ft″ == [dup dipd] dip</code></pre>')
