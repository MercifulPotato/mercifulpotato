Item(by='efreak', descendants=None, kids=None, score=None, time=1612369621, title=None, item_type='comment', url=None, parent=26001517, text='If you&#x27;re using a mobile browser on Android that doesn&#x27;t allow overriding websites that disable zoom (or using a website that defines font sizes in vw&#x2F;vh), check your accessibility settings,  there should be a shortcut for triple-tap to enable a zoom function.  Some devices have other magnifying functions as well. My tablets and phone all have the basic magnifier function; my LineageOS (android 7 &amp; 8) tablets additionally have a screen zoom&#x2F;dpi setting to modify how large both pictures and text appear,  and my samsung tablet (Android 10) has this and also a text zoom function.  There&#x27;s also a minimum view width setting in developer options since at least Android 8, to ensure interfaces aren&#x27;t too small on mobile (this only goes one way though-- there&#x27;s no maximum view width and no height controls).<p>It doesn&#x27;t help with everything,  but the triple-tap zoom is quite useful.')
