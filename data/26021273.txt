Item(by='dinkleberg', descendants=None, kids=None, score=None, time=1612400028, title=None, item_type='comment', url=None, parent=26020901, text='It&#x27;s a bit of an apples and oranges comparison. Tailwind is a utility-first css toolkit which doesn&#x27;t have pre-fabricated components. You can use one of the pre-built component libraries like TailwindUI, but Tailwind itself doesn&#x27;t include these.<p>Bulma on the other hand is a more traditional CSS framework with an existing set of components you can build on. It&#x27;s similar to Bootstrap, Semantic UI, Material UI, and many others. One notable thing about Bulma, aside from it&#x27;s nice responsive design, is it doesn&#x27;t force you to use any specific javascript library.<p>Traditional frameworks (e.g. Bulma) are great if you don&#x27;t have lots of design experience but want to build something decent looking. You just grab the snippets you want and get rolling. You can customize things, but you&#x27;ll need to learn their system.<p>Utility first is great if you know the design you want to build but don&#x27;t want to deal with writing vanilla CSS. Tailwind can speed this up quite substantially.<p>I&#x27;ve used and like both, but since I care more about doing custom designs and build my own components I almost always go for Tailwind.')
