Item(by='DanielKehoe', descendants=None, kids=None, score=None, time=1612410947, title=None, item_type='comment', url=None, parent=26022380, text='Actually I should add, I wrote a bit more nuanced recommendation in the installation guide. I say:<p>Install with Homebrew if you’re building only one project with Ruby (especially if you are a student learning Ruby). If you’re a solo developer and you&#x27;re juggling multiple projects that can&#x27;t be updated all at once, use asdf or chruby or rbenv. Choose asdf if you&#x27;re using multiple languages such as Ruby, Node, and Python; otherwise chruby or rbenv are fine for just managing Ruby versions. Finally, use Docker or Nix if you’re on a team with a complex project environment (for example, Ruby, Node, Redis, and PostgreSQL all in one project).')
