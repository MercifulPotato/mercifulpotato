Item(by='dceddia', descendants=None, kids=None, score=None, time=1612332227, title=None, item_type='comment', url=None, parent=25993624, text='Author here!<p>I wrote this post last summer after getting a chance to use Robot on a project to manage some complex state, and wanted to write an &quot;intro to state machines&quot; in the context of React.<p>We used it for things like scheduled periodic syncing of data to the server, managing app initialization when data could come from the server or localStorage and could fail (in an offline setting), and a couple other things. It gave us a lot of confidence in the code and I thought it&#x27;d be worthwhile to try to get the idea of state machines in front of more people, with a simple (and somewhat contrived for the sake of) example.<p>From the other comments I gather folks are taking this as a recommendation to use a state machine for modal dialogs, or a suggestion that this is necessary in React. My intent was more to introduce the concept of state machines with a simple example, not so much to say this is the right way to build modal dialogs :D<p>I think state machines can really help simplify some kinds of problems, and I&#x27;ve been on the lookout for places where they&#x27;re a good fit. I&#x27;d be interested to hear examples where a state machine was useful in code you&#x27;ve worked with.')
