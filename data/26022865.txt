Item(by='jart', descendants=None, kids=None, score=None, time=1612415894, title=None, item_type='comment', url=None, parent=26014580, text='I used lots of code from Musl, OpenBSD, and FreeBSD. I used Marco Paland&#x27;s printf. I used Doug Lea&#x27;s malloc. I used LLVM compiler_rt. I used David Gay&#x27;s floating point conversion utilities. The list goes on. Then I stitched it all together so it goes faster and runs on all operating systems rather than just Linux. See <a href="https:&#x2F;&#x2F;justine.lol&#x2F;cosmopolitan&#x2F;index.html" rel="nofollow">https:&#x2F;&#x2F;justine.lol&#x2F;cosmopolitan&#x2F;index.html</a> and <a href="https:&#x2F;&#x2F;github.com&#x2F;jart&#x2F;cosmopolitan" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;jart&#x2F;cosmopolitan</a><p>Trapping (SYSCALL&#x2F;INT) is a loose binding. The kernel can evolve all it wants internally. It can introduce new ABIs. Processes are also a loose binding. I think communicating with other tools via pipes and sockets is a fantastic model of cooperation. Same goes for vendoring with static linking. Does that mean I&#x27;m going to voluntarily load Linux distro DSOs into my address space? Never again. Programs that do that, won&#x27;t have a future outside Docker containers.<p>Also, my executables are VM images. They can boot on metal too. Read <a href="https:&#x2F;&#x2F;justine.lol&#x2F;ape.html" rel="nofollow">https:&#x2F;&#x2F;justine.lol&#x2F;ape.html</a> and <a href="https:&#x2F;&#x2F;github.com&#x2F;jart&#x2F;cosmopolitan&#x2F;issues&#x2F;20#issuecomment-761744274" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;jart&#x2F;cosmopolitan&#x2F;issues&#x2F;20#issuecomment-...</a> Except unlike a Docker distro container, my exes are more on the order of 16kb in size. That&#x27;s how fat an executable needs to be, in order to run on six different operating systems and boot from bios too.')
