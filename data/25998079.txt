Item(by='jart', descendants=None, kids=[25998284, 25998732, 25998216, 25998194, 25998131, 25998528], score=None, time=1612249178, title=None, item_type='comment', url=None, parent=25997624, text='There&#x27;s no good reason for a Unix system to have an unstable system call ABI. I&#x27;m sorry but companies like Apple (who broke every Go binary a few years ago) don&#x27;t get to copy syscall definitions from Bell System V and then declare it their own internal API.<p>Usually the only time the SYSCALL ABI breaks, it&#x27;s because kernel authors intentionally chose to do it for no apparent reason. For example, OpenBSD at some point changed how mmap() was defined so that it takes seven arguments:<p><pre><code>    void *sys_mmap(void *addr, size_t len, int prot, \n                   int flags, int fd, long pad, off_t pos);\n</code></pre>\nThe sixth argument doesn&#x27;t do anything. It just breaks binary compatibility. It&#x27;s also noncompliant with the System V ABI specification, which says system calls have six arguments max.<p>I work on a project called Cosmopolitan Libc which lets you create static binaries that just work on Linux + Mac + Windows + FreeBSD + OpenBSD. It was only possible to do this because Unix systems generally agree on definitions. I worked really hard to support OpenBSD since I believe in the project. I just hope they keep the ABI stable going forward.<p>For example, I&#x27;m really happy that this restriction only applies to dynamic binaries. It seems perfectly reasonable that they&#x27;d want to make the assumption that if a program chooses to link OpenBSD&#x27;s Libc that it intends to use it. That&#x27;s fine just so long as we continue having the ability to build static binaries with an alternative cross-platform Libc like Cosmopolitan.<p>Speaking of which, I think I might actually implement some of OpenBSD&#x27;s ideas in Cosmopolitan. I could probably track down all the functions that need raw SYSCALL and use __section__ so they&#x27;re all linked to the same part of the binary and then call the msyscall() function to limit it just to that page. That way as a guest libc author I&#x27;m upholding the spirit of the intent. When in Rome do as the Romans.')
