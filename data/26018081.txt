Item(by='Jtsummers', descendants=None, kids=None, score=None, time=1612380868, title=None, item_type='comment', url=None, parent=26017854, text='I think one of the points in the conclusion is that these two ideas aren&#x27;t actually on a spectrum, but rather are more orthogonal with each other. It&#x27;s not a true binary choice so there isn&#x27;t a real debate to be had between the two. Process doesn&#x27;t preclude (though it may constrain) individual empowerment, and individual empowerment does not preclude (though it may constrain) process.<p>There are processes which actually do, to some extent, encourage individual empowerment. I would put the trend to distributed version control systems like git as a boon to both process <i>and</i> individual empowerment, as an example. I can use it much more freely to experiment in my feature branch than when using a system like SVN (in many classical scenarios of using SVN), but the pull request system integrated into many git server systems is itself a process approach to control (and hopefully improve) the development work.')
