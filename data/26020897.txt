Item(by='momothereal', descendants=None, kids=None, score=None, time=1612396693, title=None, item_type='comment', url=None, parent=26020794, text='It&#x27;s for switching versions of your local CLI tools quickly.<p>&gt; asdf is a CLI tool that can manage multiple language runtime versions on a per-project basis. It is like gvm, nvm, rbenv &amp; pyenv (and more) all in one! Simply install your language’s plugin!<p>For example:<p><pre><code>    $ asdf global python 3.6.2\n    $ python -V\n    Python 3.6.2\n\n    $ asdf local python 3.9.1\n    $ python -V\n    Python 3.9.1\n</code></pre>\n&quot;asdf local&quot; stores the version to use for the current directory across shells, which is neat. &quot;shell&quot; is for the current session, and &quot;global&quot; is for the system.<p>The supported CLI tools is extendable via plugins: <a href="https:&#x2F;&#x2F;asdf-vm.com&#x2F;#&#x2F;plugins-all" rel="nofollow">https:&#x2F;&#x2F;asdf-vm.com&#x2F;#&#x2F;plugins-all</a>')
