So even if you did a pure rust libstd (like the now defunct Steed[0]), you&#x27;d still need to either manually link that libc (breaking the mitigation), or rebuild your program each time the distro updates either libstd or the rust compiler.<p>I&#x27;m not sure what the situation for Go is. Assuming Go has proper support for dynamic loading and a stable ABI, it would be doable.<p>[0]: <a href="https:&#x2F;&#x2F;github.com&#x2F;japaric&#x2F;steed" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;japaric&#x2F;steed</a>')
