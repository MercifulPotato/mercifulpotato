Item(by='Blikkentrekker', descendants=None, kids=None, score=None, time=1612330465, title=None, item_type='comment', url=None, parent=26010387, text='That would mitigate the problem of easily finding out what options there are, but it would still be a form of weak typing where a best guess is substituted for a mistake.<p>If the system administrator truly intend for a value to be default, he should explicitly declare it so in the configuration file.<p>Interpreting the system administrator&#x27;s act of forgetting something as his intention for it to be a default value, seems like a bad idea to me.<p>As for merge, I find it as annoying if software not support configuration directories. `foo.conf` should exist alongside `foo.conf.d`, and if the latter exist, it&#x27;s contents should be parsed as well.<p>On an update, the system can simply install a file in `foo.conf.d` which contains the default of any new keys added from the last version.')
