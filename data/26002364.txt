Item(by='spijdar', descendants=None, kids=[26002436, 26003185, 26002459, 26002627], score=None, time=1612280981, title=None, item_type='comment', url=None, parent=26001851, text='Professional pentester here - Wayland alone doesn&#x27;t really do much for you, security wise. It is still very possible for an application simply running under a wayland compositor to do lots of nasty things.<p>The Wayland protocol provides the building blocks for someone to create an Android-like sandboxed environment, but doing so would break every application. Snaps and Flatpak come closer, but still generally miss the mark, since many applications require your entire home directory to be bind mounted in their container.<p>Running wayland alone gets you very little in terms of sandboxing. It locks the front door, but leaves the backdoor and all your windows open, because that&#x27;s what every application under the sun expects.<p>&gt; Under X11, you are basically running every application with root, always.<p>This is ... not true, either broadly or generally. You&#x27;re saying this because Xorg runs as root, which means that any security flaw in Xorg yields root access. I think saying that &quot;you are running every application with root&quot; is stretching it a bit, but I&#x27;ll accept it.<p>But Xorg doesn&#x27;t <i>have</i> to run as root. OpenBSD started it years ago with Xenocara, but AFAIK Fedora also does not run Xorg as root. I&#x27;m not sure what other OSes are doing, but it&#x27;s at least not a flaw of X11 in general, just a flaw of <i>Xorg</i>.')
