Item(by='jzer0cool', descendants=None, kids=None, score=None, time=1612306400, title=None, item_type='comment', url=None, parent=26002656, text='Technical documentation is so underrated.  I find it is a make or break situation and should be as important to the software development cycle.  Maybe a SWE and good technical writer is hard to find?  A lot of times we are pressured and rewarded for code, bug fixes, etc., rather than to document.  I find often the reverse to be true although not proven.  If documentation is well kept and maintained, I wonder how much time is given back over it&#x27;s course?  Just like code, documentation is also iterated and improved upon.<p>As food for thought, what changes would occur if documentation must be created first before any coding takes place?  How about if produced in parallel?  Too often, it is an artifact at the end.')
