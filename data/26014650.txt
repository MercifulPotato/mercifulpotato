Item(by='dkonofalski', descendants=None, kids=None, score=None, time=1612367101, title=None, item_type='comment', url=None, parent=26002577, text='This is just an opinion but I&#x27;m a big fan of Apple and have been using their machines for a long time. There are just some new conventions that have been introduced alongside hardware that add complexity that I don&#x27;t think is possible to get right the first time around outside of some pretty minimum functionality. Any time an process needs to be re-thought or redefined, you&#x27;re basically starting from scratch even if the end results look similar. In the example I gave, Notification Center was something that had to be ported over from iPadOS&#x2F;iOS (and I&#x27;m glad it did as I find it very useful and much more consistent of an experience) but it then needed to be retro-fit to handle applications that weren&#x27;t originally intended for it. It also needs to deal with notifications in a way that make them consistent so that new users pick up the basics of how it works easily. To me, that&#x27;s a hard task. I just wish there was a bit more consideration taken towards keeping existing functionality in place, even if it contradicts new paradigms, but that&#x27;s really a design choice that I just have to disagree with because the alternative is probably better for most people using the machines. If it&#x27;s not, the analytics will bear that out and they&#x27;ll change it to the one that I prefer.')
