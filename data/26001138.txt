Item(by='santigr', descendants=None, kids=None, score=None, time=1612275242, title=None, item_type='comment', url=None, parent=25992782, text='<a href="https:&#x2F;&#x2F;github.com&#x2F;sgrodriguez&#x2F;ddt" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;sgrodriguez&#x2F;ddt</a> a decision tree lib in golang for building custom rules decision tree. It allows adding a pre-processing stage to the input before comparing it with the following possible branches of the tree. One of the default preprocessing stages in ddt is calling a method of a struct (CallStructMethod) and getting the attribute of a struct (GetStructAttribute) using reflection, so you can have a struct user with some methods and attributes and build a tree asking question about the user.\nCreate the tree programmatically or by json.')
