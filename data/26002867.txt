Item(by='gregmac', descendants=None, kids=None, score=None, time=1612282864, title=None, item_type='comment', url=None, parent=26002413, text='&gt; Individually, these things are small, but the small impedances these changes introduce does take a toll on people, especially when you&#x27;re trying to just get stuff done.<p>One of the problems is a parity disconnect. A developer&#x2F;PM often has very different perspective from their users: They see the new changes as they&#x27;re happening and so they&#x27;re all small, incremental changes, plus they&#x27;re closely following development.<p>A lot of users only infrequently update and&#x2F;or infrequently use certain features, and so for them, all these small incremental features add up to be massive change for the sake of change. This will often manifest as &quot;Every time I go to do x, it&#x27;s totally different and I have to re-learn everything!&quot;.<p>I find a lot of software -- especially FOSS -- also communicates change poorly. Release notes are the primary way to get across changes, yet there are several bad things people do that make it basically impossible to read:<p>* List every change or commit message, especially without categorizing or simplifying the wording<p>* Don&#x27;t properly highlight feature changes (eg with screenshots and&#x2F;or reasoning)<p>* Have dozens of betas&#x2F;pre-releases, but don&#x27;t consolidate the release notes into a final &quot;here&#x27;s what&#x27;s changed since the last main release&quot; document<p>Some examples of exceptionally good release notes: Visual Studio Code [1], Jira [2], Gitlab [3]  (though if they only provided their changelog [4] it would be a good example of being overly verbose to the point of unusable).<p>[1] <a href="https:&#x2F;&#x2F;code.visualstudio.com&#x2F;updates&#x2F;v1_52" rel="nofollow">https:&#x2F;&#x2F;code.visualstudio.com&#x2F;updates&#x2F;v1_52</a><p>[2] <a href="https:&#x2F;&#x2F;confluence.atlassian.com&#x2F;jirasoftware&#x2F;jira-software-release-notes-776821069.html" rel="nofollow">https:&#x2F;&#x2F;confluence.atlassian.com&#x2F;jirasoftware&#x2F;jira-software-...</a><p>[3] <a href="https:&#x2F;&#x2F;about.gitlab.com&#x2F;releases&#x2F;categories&#x2F;releases&#x2F;" rel="nofollow">https:&#x2F;&#x2F;about.gitlab.com&#x2F;releases&#x2F;categories&#x2F;releases&#x2F;</a><p>[4] <a href="https:&#x2F;&#x2F;gitlab.com&#x2F;gitlab-org&#x2F;gitlab-foss&#x2F;-&#x2F;blob&#x2F;master&#x2F;CHANGELOG.md" rel="nofollow">https:&#x2F;&#x2F;gitlab.com&#x2F;gitlab-org&#x2F;gitlab-foss&#x2F;-&#x2F;blob&#x2F;master&#x2F;CHAN...</a>')
