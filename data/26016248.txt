Item(by='kstrauser', descendants=None, kids=[26016398], score=None, time=1612373414, title=None, item_type='comment', url=None, parent=26016106, text='Even then it&#x27;s better than nothing. If every company used different salt, rainbow tables would have to be completely regenerated for each company.<p>(This is still awful, because then two users with the same password would have the same digest. If you know that joe@example.com has password &quot;badpass&quot;, and jane@example.com has the same hashed password, then hers is also &quot;badpass&quot;. So use randomly per-user salts, gang! Even better, pick a tested implementation of PBKDF2 or Argon2 and use that implementation. Don&#x27;t roll your own crypto!)<p>But still, it&#x27;s better than nothing.')
