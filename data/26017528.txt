Item(by='arendtio', descendants=None, kids=None, score=None, time=1612378387, title=None, item_type='comment', url=None, parent=26010469, text='Actually, I am more of a POSIX shell person, so I would like to add<p><a href="https:&#x2F;&#x2F;shellhaters.org" rel="nofollow">https:&#x2F;&#x2F;shellhaters.org</a><p>It is a simple page with links to the corresponding parts of the POSIX standard which makes it a lot easier to find the correct documentation when you need it.<p>For those who wonder what POSIX is: It is a standard for operating systems and one part is about shells. So if a shell whats to be POSIX compliant it has to support certain commands. And if you write POSIX commpliant scripts, they won&#x27;t just run on Linux, but also on MacOS, other BSDs and other POSIX compliant operating systems. Bash supports POSIX, but if you use Bash extensions that are not part of POSIX, you <i>might</i> run into trouble with other shells (e.g. dash on Debian).')
