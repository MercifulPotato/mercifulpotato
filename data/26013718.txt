Item(by='vouwfietsman', descendants=None, kids=None, score=None, time=1612361627, title=None, item_type='comment', url=None, parent=26013287, text='For sure mimalloc is interesting!<p>At work we&#x27;ve been able to use mimalloc to great effect, using it as a drop-in replacement for the standard msvc allocator showed 3x runtime (!) improvements on multi-minute workloads. In terms of memory use we also saw improvements, but less dramatic.<p>Of course these numbers mean nothing without context (and there was much more heap allocation going on than needed), but getting that kind of performance improvement for (comparatively) such little effort really changed my view on memory and optimization.<p>Not the most user-friendly library though, perhaps that is a result of its selling point: 0 code changes needed.')
