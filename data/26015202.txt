Item(by='searine', descendants=None, kids=[26015609, 26016057], score=None, time=1612369509, title=None, item_type='comment', url=None, parent=26014831, text='They are a fun tool, great for doing molecular work in the field. The error rate is still very high compared to short reads, but if you know this and plan for it going in you should be fine.<p>Flowcells last for one sample. The machine should last indefinitely. You can sometimes add more of the same DNA to a flowcell after one use to get a bit more out of it, but the quality degrades quickly. 500-1000 dollars each for flowcells, depending on how much you order.<p>My experience in field use, I was using Oxford Nanopores software which does processing remotely and was able to run the the platform on just a regular 2015-era laptop.')
