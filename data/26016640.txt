Item(by='AnthonyMouse', descendants=None, kids=[26017453, 26016937], score=None, time=1612374911, title=None, item_type='comment', url=None, parent=26015096, text='I&#x27;ve never really loved this advice.<p>If people use weak passwords, the hash algorithm doesn&#x27;t matter, they&#x27;re going to get cracked. If you use strong passwords, the hash algorithm doesn&#x27;t matter, they&#x27;re not going to get cracked. This sort of thing only matters for medium passwords. And can be avoided by requiring strong passwords.<p>It also does very little against precomputation attacks (e.g. rainbow tables), because it makes it take longer to compute the tables but it&#x27;s still efficient to use them.<p>Meanwhile it adds a user-perceptible amount of latency to logging in, because the hash algorithm is so slow. That causes users to take steps to avoid it, e.g. by staying logged in when they don&#x27;t need to or preventing their machine from locking, which reduces security.')
