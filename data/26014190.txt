Item(by='kn8', descendants=None, kids=[26018123], score=None, time=1612364673, title=None, item_type='comment', url=None, parent=26010116, text='For what it&#x27;s worth, I&#x27;ve been working on a state machine library that&#x27;s more deeply integrated into React: <a href="https:&#x2F;&#x2F;github.com&#x2F;humaans&#x2F;react-machine" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;humaans&#x2F;react-machine</a>.<p>It does a few things differently from XState &#x2F; Robot bindings:<p>1. Use React&#x27;s useReducer for state transitions and useEffect for applying the effects.<p>2. Allow reacting to component props (or machine context) and transitioning within the same render where props changed (achieved with a dispatch in the render body). This means the component&#x27;s children get rendered with props and machine state that is in sync.<p>3. Separate machine&#x27;s context (often component props) from machine&#x27;s state. This reduces the number of unnecessary rerenders, while allowing your machine&#x27;s reducers and effects to use up to date data and functions passed via props.<p>All in all, it&#x27;s my exploration of how to more tightly integrate statecharts into React&#x27;s render lifecycle and programming model.')
