Item(by='sighingnow', descendants=None, kids=None, score=None, time=1612403589, title=None, item_type='comment', url=None, parent=26018217, text='Thanks for you interests on GraphScope!<p>We do have a concrete plan for k8s-less deployment and we already have an issue [1] to track that. That will be available before the end of March 2021.<p>To simplify the environment setup process we will release a docker image for end-users, but without docker will be ok as well (requires building from sources).<p>GraphScope use vineyard [2] as the storage layer for im-memory graph data structures. And current the graph type (aka. ArrowPropertyFragment in GraphScope) uses a set of arrow tables and arrays under the hood.<p>GraphScope supports a `to_vineyard_dataframe` method on the computation context [3]. We also has a plan for integration between vineyard and dask (may could be delivered in March as well). At that time the interop between dask would be straightforward.<p>[1]: <a href="https:&#x2F;&#x2F;github.com&#x2F;alibaba&#x2F;GraphScope&#x2F;discussions&#x2F;113" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;alibaba&#x2F;GraphScope&#x2F;discussions&#x2F;113</a><p>[2]: <a href="https:&#x2F;&#x2F;github.com&#x2F;alibaba&#x2F;libvineyard" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;alibaba&#x2F;libvineyard</a><p>[3]: <a href="https:&#x2F;&#x2F;graphscope.io&#x2F;docs&#x2F;reference&#x2F;context.html#graphscope.framework.context.BaseContext.to_vineyard_dataframe" rel="nofollow">https:&#x2F;&#x2F;graphscope.io&#x2F;docs&#x2F;reference&#x2F;context.html#graphscope...</a>')
