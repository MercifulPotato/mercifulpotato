Item(by='seer', descendants=None, kids=[26011955], score=None, time=1612334010, title=None, item_type='comment', url=None, parent=26006041, text='I used to think this way too, but working over the years with TypeScript has gotten me so accustomed to it that it’s now the other way around. I feel much more productive in TS in general.<p>With TS its like you’re writing the unit test and your code at the same time, and if your types are expressed well enough you can also skip the compile+run+verify step.<p>I’ve had cases where I would spend <i>days</i> just writing code, refactoring and iterating, without building the project once, compile it at the end, and have a complex feature work correctly on first try, passing all the functional tests.<p>It’s like I have a pair working with me constantly compiling my code and pointing out syntax and interface errors while I concentrate on the business logic and big picture stuff.<p>When I go back to JS it’s as if I now have to do all that manual labour too, as well as constantly write and run unit tests myself to make sure what I write actually works.<p>Though it definitely took some time to get this comfortable with the TS type system.')
