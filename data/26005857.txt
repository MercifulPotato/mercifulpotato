Item(by='int_19h', descendants=None, kids=None, score=None, time=1612296293, title=None, item_type='comment', url=None, parent=26005553, text='Most browsers have a &quot;minimum font size&quot; setting, which would be applicable here.<p>In general, CSS already provides a bunch of generic font families and sizes. So a page <i>could</i> style something as e.g. &quot;sans-serif&quot; and &quot;large&quot; - and then the browser should figure out what this actually means according to user settings. The problem is that very few sites actually use these. But for those that do, the browsers do the right thing - and, again, most of them let you configure what the generic font families map to.')
