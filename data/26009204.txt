Item(by='SomeCallMeTim', descendants=None, kids=None, score=None, time=1612313058, title=None, item_type='comment', url=None, parent=26008181, text='Totally agree with you.<p>Some of the rebuttals below seem to be saying &quot;But I use them differently!&quot; Bully for them, but 99% of the time when it&#x27;s not set, you don&#x27;t really care why it&#x27;s not set because it&#x27;s not defined yet or because it&#x27;s been set to `null`.<p>And any time they assume it can only be null OR undefined but not either, there&#x27;s a chance for a bug. Even if I &quot;know&quot; it can only ever be null and not undefined, it&#x27;s safer to just say != null rather than !== null.<p>Treating them differently in a code base is a legit <i>semantic</i>, but testing with != null works no matter the intended semantics.')
