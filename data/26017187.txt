Item(by='dwheeler', descendants=None, kids=None, score=None, time=1612376875, title=None, item_type='comment', url=None, parent=26015096, text='I completely agree. If you&#x27;re directly using a SHA hash for password storage, even with salt, you&#x27;re doing it so incompetently that you should probably be fined.<p>At the very <i>least</i> use a well-studied <i>iterated</i> salted hash algorithm for storing passwords (if you must authorize an incoming request later). That is a <i>minimum</i> bar. I generally recommend argon2. Reasonable alternatives are bcrypt, scrypt, and PBKDF2. PBKDF2 is weak against hardware, but it&#x27;s still better than using a hash directly.<p>I teach a class on developing secure software, and students have to do a final project. I take off points if they directly use SHA for password storage; that&#x27;s just not acceptable.')
