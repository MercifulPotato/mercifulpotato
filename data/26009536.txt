Item(by='ytjohn', descendants=None, kids=None, score=None, time=1612315856, title=None, item_type='comment', url=None, parent=25995030, text='I may have done something wrong, but I remember that when I would do &#x27;return {&quot;json&quot;: &quot;yes&quot;}&#x27;, it would not set the content-type to json. When I discovered this, I had to go back through a bunch of code and convert it to either fastaspi.Response or JSONResponse.<p>Creating the Response instance proved to be a better approach, because it makes it much easier to set content type, status codes, cookies, headers, etc.<p>Again - I might have done something wrong, but if you have an instance just doing &#x27;return {&quot;key&quot;: &quot;value&quot;}&#x27;, check it with curl or browser dev tools to see what the Content-Type is.')
