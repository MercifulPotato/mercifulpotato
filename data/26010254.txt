Item(by='flowerlad', descendants=None, kids=[26010861, 26010452, 26010753], score=None, time=1612322662, title=None, item_type='comment', url=None, parent=25993624, text='This is a good example of how fucked up React can be when you religiously follow &#x27;UI is a function of state&#x27; principle.<p>A dialog should return a promise. Then you can mix confirmation dialog, fetch calls and so on like this:<p><pre><code>  private async doTheThing(): Promise {\n      try {\n         await Confirm(&quot;Really do it?); &#x2F;&#x2F; Promise rejects if user presses No\n         const options = await OptionsDialog();\n         await makeFetchCall(options);\n         await showSuccessDialog();\n      }\n      catch (ex) {\n         showError(ex);\n      }\n  }\n</code></pre>\nYes, that&#x27;s imperative code, which violates React principles. But it is insanely simple compared to typical React code.')
