Item(by='ParadigmComplex', descendants=None, kids=None, score=None, time=1612269517, title=None, item_type='comment', url=None, parent=25996965, text='Ah, I now see what you mean.  With the exceptions of &#x2F;var&#x2F;lib&#x2F;dbus&#x2F;machine-id and &#x2F;var&#x2F;run, which need to be shared for certain bits of software to communicate properly, &#x2F;var is currently isolated by default.  If a website is hosted at &#x2F;var&#x2F;www or e-mail contents stored at &#x2F;var&#x2F;spool&#x2F;mail, a naive implementation of the rollback system swsieber described would roll back the website and e-mail as well.  Bedrock can be easily configured to make such directories shared across the system and exempted from such a rollback system; hopefully any user who attempts such a workflow would catch this issue and change Bedrock configuration accordingly.  I should probably investigate making such configuration default.')
