Item(by='iandinwoodie', descendants=None, kids=None, score=None, time=1612413285, title=None, item_type='comment', url=None, parent=26022531, text='A virtualenv (venv) does not install its own copy of Python. Instead, when you create the venv it puts symlinks for the calling python in the &lt;venv&gt;&#x2F;bin directory. When you activate the venv the &lt;venv&gt;&#x2F;bin is added to the front of your PATH so that any &quot;python&quot; commands use the symlink&#x27;ed version of Python corresponding to your venv.')
