Item(by='lxgr', descendants=None, kids=None, score=None, time=1612295447, title=None, item_type='comment', url=None, parent=26003601, text='I&#x27;m talking about a userspace-only Linux compatibility layer for Windows.<p>As far as I understand, Wine (a userspace-only Win32 emulator) is possible because Windows applications always go through the standard library for system calls, which therefore can be hooked without kernel support.<p>The same is not generally true for Linux binaries – these usually do go through glibc, but direct syscalls are possible (through raising the appropriate interrupt or instruction).<p>I don&#x27;t think there&#x27;s an easy way to trap these without kernel support (which is what WSL 1 has been doing).')
