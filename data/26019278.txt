Item(by='tomnipotent', descendants=None, kids=[26019442], score=None, time=1612387348, title=None, item_type='comment', url=None, parent=26019184, text='This is intended for analytical workloads where you&#x27;re often doing things that can benefit from vectorization (like SIMD). It&#x27;s much faster to SUM(X) when all values of X are neatly laid out in-memory.<p>It also has the added benefit of eliminating serialization and deserialization of data between processes - a Python process can now write to memory which is read by a C++ process that&#x27;s doing windowed aggregations, which are then written over the network to another Arrow compatible service that just copies the data as-is from the network into local memory and resumes working.')
