Item(by='brucehoult', descendants=None, kids=None, score=None, time=1612300663, title=None, item_type='comment', url=None, parent=26005871, text='x86_64 instructions can be anything from 1 byte to 15 bytes long. You have to decode the entire instruction, except any trailing constant&#x2F;offset, to even know how long the instruction <i>is</i>.<p>RISC-V instructions can be exactly two lengths: 2 bytes or 4 bytes. You can tell how long an instruction is by looking at the first 2 bits: 11 -&gt; the instruction is 4 bytes long, anything else (00, 01, 10) -&gt; the instruction is 2 bytes long.<p>These things are so different that you can&#x27;t just say &quot;oh, they&#x27;re both variable length&quot;.<p>Also, the 2 byte instruction in RISC-V are completely <i>optional</i>. They each exactly duplicate some 4 byte instruction. If you want to build an 8-wide machine like the M1 and you think having two instruction lengths will make that too hard -- you can just use the fixed length RISC-V base instruction set instead. The only downside is your programs will be a bit bigger, and you&#x27;ll need to compile your own software (as Apple, for example, does).')
