Item(by='mgoetzke', descendants=None, kids=None, score=None, time=1612363516, title=None, item_type='comment', url=None, parent=26013690, text='In our system (has event-sourcing parallels) we can optionally use it by chaining subsequent event hashes to each other and letting blocks of such events be signed by an external signing server.<p>This does not require a bitcoin de-centralized signing process though and is better done via a normal external authority.<p>It is now harder to falsify server data, since you not only have to recreate all hashes from the moment of change in the event log, but also have them be authenticated by the external source. In addition to the underlying ZFS snapshots a lot needs to be compromised to change data without detection')
