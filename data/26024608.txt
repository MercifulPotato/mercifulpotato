I&#x27;ts a bit too tricky for me.<p>I have resorted to using a throwaway dev container which mimics the local storage of packages. Hopefully someone find the below bash function useful.<p>The only issue I have using this method is that I cant use VSCode to Debug, which I am hoping to find a nice solution for, but nothing yet.<p><pre><code>  function python() {\n     docker run \\\n         -it --rm \\\n         --name python_$(pwd | sed &#x27;s#&#x2F;home&#x2F;##g&#x27; | sed &#x27;s#&#x2F;#.#g&#x27;)_$(date +&quot;%H%M%S&quot;) \\\n         -u $(id -u):$(id -g) \\\n         -v &quot;$(pwd)&quot;:&quot;$(pwd)&quot; \\\n         -w &quot;$(pwd)&quot; \\\n         -e PROJECT_ROOT=&quot;$(pwd)&quot; \\\n         -e PATH=&quot;$(pwd)&#x2F;vendor&#x2F;bin&#x2F;:${PATH}&quot; \\\n         -e PYTHONUSERBASE=&quot;$(pwd)&quot;&#x2F;vendor \\\n         -e PYTHONDONTWRITEBYTECODE=1 \\\n         -e PIP_NO_CACHE_DIR=1 \\\n         --net=host \\\n         -h py-docker \\\n         python:3-slim \\\n         &#x2F;bin&#x2F;bash -c &#x27;&#x2F;bin&#x2F;bash --rcfile &lt;(echo &quot;PS1=\\&quot;[$(python --version)]:: \\&quot;&quot;) -i&#x27;\n }</code></pre>')
