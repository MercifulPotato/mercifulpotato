Item(by='kelnos', descendants=None, kids=[26009123], score=None, time=1612304244, title=None, item_type='comment', url=None, parent=26006697, text='You don&#x27;t really &quot;compile stuff yourself&quot; on Gentoo.  There&#x27;s still a package manager, and it does all the building and installing for you.  Yes, compilation happens as a result of the user invoking the package manager, but there&#x27;s a huge usability difference between &quot;emerge foo&quot;, and download foo.tar.gz -&gt; unpack -&gt; configure&#x2F;build&#x2F;install -&gt; track updates and repeat as needed.  I would call the latter &quot;compiling foo yourself&quot;, but not the former.')
