Item(by='qbasic_forever', descendants=None, kids=None, score=None, time=1612388510, title=None, item_type='comment', url=None, parent=26019470, text='For totally greenfield python projects check out poetry, it is an opinionated python project workflow that&#x27;s very close to the nodejs&#x2F;npm ecosystem&#x27;s package.json.  It does a virtualenv behind the scenes, pins your python dependencies with a lock file, and even has niceties like dev scripts as first class citizens.<p>Otherwise if you&#x27;re trying to use some python project with particular dependencies pyenv is a good way to get a specific python version.  But if the project has a lot of native dependencies (think scientific computing with lots of fortran, C++, etc. code to compile) then you&#x27;re almost certainly better off with conda as a higher-level entire binary system manager.')
